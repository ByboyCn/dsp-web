📖 设计数据说明
四个数组均可自由增删改（JSON）。保存后新进玩家的刷新页面即生效。
quests 任务：{ id, name, desc, metric, item?, target, reward } · metric ∈ collect（背包物品总数）/ place（item=建筑类型，统计已放置数）/ produce（item=物品id，累计产出）/ store（item=物品id，仓库+背包存量）/ tech（item=科技id）/ inventory（item=物品id，背包数）； reward = { 物品id: 数量 }，完成自动发放进背包。
techs 科技：{ id, name, desc, cost:{物品:数量}, time(秒), requires?(前置科技id), unlocks?(建筑类型 / recipe:配方id) }
upgrades 升级：{ id, name, desc, max, base:{物品:数量}(每级×2), multKey ∈ mine/belt/smelt/assemble/mecha, per(每级倍率) }
buildings 建筑：{ type(已知类型见下), name, desc, color, tech(解锁科技id), powerDemand, supply, radius, fuelItem?, fuelRate?, buildItem, cost:{物品:数量}(手搓配方) }
已知建筑 type：Miner, Smelter, Assembler, Belt, Storage, WindTurbine, PowerPylon, Substation, ThermalPowerPlant, SolarPanel （新增未知 type 会被当作装饰建筑渲染——无专属外观与模拟逻辑）
